## Architecture
- **Account** = billing unit (owns subscriptions, plans define max workspaces/users)
- **Workspace** = operational unit (chat, widget, domains, settings)
- Account → many Workspaces; User → AccountMember → Account
- Signup auto-provisions account + first workspace via `handle_new_user` trigger → `provision_account_on_signup` RPC

## Slug System (CRITICAL)
- Workspace slugs: `ws_` + 8-char hex (e.g. `ws_a3f7b2c1`) — generated by `generate_short_id('ws_')`
- Account slugs: `acc_` + 8-char hex
- Slugs are NEVER derived from user input (no company name, no user name)
- ASCII-only, URL-safe, immutable after creation
- `create_workspace_atomic` validates slug format or auto-generates

## Routing (CRITICAL)
- Active workspace is **strictly route-based**: `/app/w/:slug`
- `useActiveWorkspace()` resolves workspace by matching `:slug` against user's workspace list
- If slug doesn't match → `notFound: true` → shows WorkspaceNotFound page
- **NO fallback** to previous, first, or cached workspace — ever
- `/app` redirects to first workspace via `WorkspaceRedirect`
- `useWorkspacePath()` builds workspace-scoped paths

## Workspace Creation
- Always via `create_workspace_atomic` RPC (transactional: workspace + member + branding + widget)
- Slug is auto-generated server-side, not from user input

## Key Files
- `src/hooks/useWorkspace.ts` — workspace hooks
- `src/features/workspace/WorkspaceRedirect.tsx` — /app redirect
- `src/features/workspace/WorkspaceNotFound.tsx` — 404 for invalid slugs
- DB functions: `provision_account_on_signup`, `create_workspace_atomic`, `generate_short_id`
